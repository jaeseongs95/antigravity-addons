# Architecture & Vendor Independence (`v2.1.0` / `v2.0.0`)

`antigravity-native-addon-host` v2.1.0 (building additively on v2.0.0) follows a strict hexagonal (Ports & Adapters) design with SOLID ISP/DIP enforcement (`TC-001`–`TC-001d`, `TC-014`, `TC-023`) and a zero-dependency staged runtime (`dist/runtime/` + `runtime/<buildSha8>/`):

- **`src/core/` (Vendor- & Runtime-Neutral Policy — `TC-001`, `TC-023`)**:
  - `fs-port.js`: runtime-neutral `FileSystemPort` abstraction (`existsSync`, `isFileSync`, `realpathSync`, `resolve`, `normalize`, `relative`, `isAbsolute`, `join`, `sep`) so `src/core/` has zero direct `node:fs` or `node:path` imports.
  - `host-profile-port.js`: minimal runtime-neutral `HostProfile` contract (`id`, `resolvePaths`) with zero Electron, ASAR, or vendor fields.
  - `host-ports.js`: segregated CLI ports (`HostLifecyclePort` [6 methods] and `AddonStorePort` [4 methods], preserved unchanged under `Option B-Clean`) plus optional `TrustPolicyPort` (`loadPolicy`, `verifyPluginTrust`, `approvePlugin`, `revokePlugin`, `listApproved`).
  - `trust-policy-port.js`: pure Default-Deny SHA-256 trust evaluator (`evaluateTrustDecision`, `getPrivilegedRequirements`).
  - `manifest-normalizer.js` & `manifest-validator.js`: executes pre-compiled 0-dep standalone `Ajv` validators (`src/core/generated/validate-v1.cjs`, `validate-v2.cjs`, with localized 0-dep helpers `equal.cjs` / `ucs2length.cjs`), normalizes frozen `AddonManifest.v1` and `AddonManifest.v2` into a unified v2 representation, enforces strict SemVer 2.0.0 compatibility, explicit `trustLevel` (`trusted` | `restricted`) + `strictTrustPolicy: true` defaults, and `<pluginsRoot>/<pluginId>/` realpath symlink confinement via injected `FileSystemPort`.
  - `slot-registry.js`: null-prototype (`Object.create(null)`) exclusive slot, `storageNamespace`, and `ipcChannelPrefix` collision detector.
  - `lifecycle-coordinator.js`: deterministic `(loadOrder, pluginId)` sorting, duplicate `pluginId` rejection, read-only enabled-gate filtering, and fault-isolated execution planning.
- **`src/cli/` (Host-Agnostic CLI Factory — `TC-001c`, `TC-014`)**:
  - `main.js`: `createCliApp({ hostLifecycle, addonStore, trustPolicy, defaultProfile })` resolves an opaque host context strictly once per CLI invocation, delegates `--validate`, `--register`, `--unregister`, `--status`, `--doctor` (including `trustPolicy` integrity & unapproved active trusted addon detection), `--install` (`--replace-legacy`, `--refresh-orig`), `--upgrade`, `--rollback` (`--force`), and `trust approve` / `trust revoke` / `trust list` exclusively through segregated ports, with zero `ctx.paths` assumptions, zero `node:fs` writes/locks, zero Electron/ASAR fields, and zero concrete adapter/profile imports.
- **`src/adapters/node-fs-port.js` & `src/adapters/fs-lock-atomic.js` (Host-Neutral I/O, Lock & Atomic Write Utilities — `TC-001d`, `TC-023`)**:
  - `node-fs-port.js`: Node.js implementation of `FileSystemPort`.
  - `fs-lock-atomic.js`: standalone `proper-lockfile` exclusive locking and atomic rename-write helpers with zero `@electron/asar` or `acorn` coupling.
- **`src/adapters/electron/` (Electron Host Adapter — `TC-001b`, `TC-001d`, `TC-019`–`TC-022`, `TC-V2-001`–`TC-V2-008`)**:
  - `electron-host-profile-port.js`: validates Electron/ASAR/URL/anchor fields, forbids `process.env.*` path overrides in production ASAR anchors (`ERR_ANCHOR_ENV_OVERRIDE_FORBIDDEN`), and validates required resolved paths (`ADDONS_DIR`, `PLUGINS_ROOT_DIR`, `LOADER_SCRIPT_PATH`, `ASAR_PATH`, `ASAR_LOCK_PATH`).
  - `electron-host-lifecycle-port.js`, `electron-addon-store-port.js` & `trust-policy-store.js`: segregated `HostLifecyclePort`, `AddonStorePort`, and `TrustPolicyPort` implementations. `installHost` / `upgradeHost` fail closed if `dist/runtime/build-manifest.json` or required entries are missing (`ERR_DIST_RUNTIME_MISSING`), verify existing `runtime/<buildSha8>/` integrity before reuse, stage immutable runtime files and `addon-host-loader.js` atomically under `ADDONS_LOCK_PATH`, apply ASAR patching, and compensate cleanly on any failure. `getHostStatus` / `diagnoseHost` inspect the actually installed loader's `buildSha8` and staged runtime files.
  - `config-reader.js`: read-only fail-closed `config.json` reader using `Object.hasOwn`.
  - `asar-patcher.js` & `asar-patch-transport.js`: `@electron/asar` + `acorn` character-offset exact-size patcher and syntax verifier, clean `BACKUPS_DIR` (`~/.gemini/antigravity/backups/`) `.orig` / `.orig.json` / `index.json` storage with `N=3` retention pruning and zero writes into vendor `resources/` (including during legacy V1 -> V2 `.orig` migration), `UPDATED_UNPATCHED` vs `rolledBackAt` tracking, fail-fast `EBUSY`/`EPERM` handling (`ERR_TARGET_LOCKED_APP_RUNNING`), build-hash identity guard (`ERR_ORIG_BUILD_MISMATCH`), and `patchedSha256` rollback verification.
  - `host-loader-builder.js`: generates the thin `addon-host-loader.js` entry shim delegating `initMain(app)` (pre-`app.whenReady()`) directly to the staged content-addressed `runtime/<buildSha8>/main/init-main.js` bundle with zero development repository paths and zero runtime `node_modules`.
- **`src/runtime/` & `dist/runtime/` (Zero-Dependency Staged Runtime — `npm run build:runtime` / `npm run check:runtime`)**:
  - **Main (`src/runtime/main/`)**:
    - `init-main.js`: orchestrates pre-ready initialization, IPC handlers (`VERIFY_FRAME`, `CLAIM_NONCE`, `REPORT_ERROR`, `PORTAL_CLAIM`, `PING`), `mainHookRunner`, and `rendererInjector`.
    - `preload-registrar.js`: registers `preload-bridge.cjs` strictly on `session.defaultSession` via `app.prependOnceListener('ready', ...)` (before host `app.on('ready')` window creation, with `whenReady()` fallback), leaving isolated partitions untouched.
    - `host-origin-resolver.js`: validates `senderFrame === mainFrame`, protocol+host, rejects opaque `'null'` origins on HTTP(S), issues single-claim `claimNonce` with UTF-8 byte-length-checked `crypto.timingSafeEqual`, and enforces fail-closed integer `docGenId` checks on `verifyClaimedEvent`.
    - `portal-arbiter.js`: non-destructive dual-source `ipcMain.handle` wrapper keyed strictly by `webContents.id`, revoking plugin claims on committed `did-navigate`, `render-process-gone`, and `destroyed` (degrading cleanly to `PORTAL_ARBITER_DEGRADED_LOCAL` if unsupported).
    - `trust-verifier.js` & `main-hook-runner.js`: single-buffer SHA-256 verification for trusted renderer scripts; fail-fast pre-trust check, `st.size`/directory-capped realpath-confined in-memory bundle snapshot, and in-memory CommonJS loader for explicitly SHA-256-approved `mainHook` bundles (blocking `require()` of `fs`, `electron`, `node_modules`, absolute paths, `file://`, and `.mjs` as a TOCTOU and casual-`require()` guard — not an OS sandbox; OS-level `SidecarBridge` isolation is deferred to `v2.1.0` under `Option S1`), with per-plugin serialized `opChain` and least-privilege frozen brokers.
    - `settings-bridge.js` (`v2.1.0`): unidirectional read-only host settings file watcher/reader strictly confined to `HOST_DATA_DIR` (`lstatSync` symlink rejection, `realpathSync` confinement, reserved host filename/path protection, pre/post-read `maxBytes` cap, `parseSafeJson` prototype-pollution blocking, single debounced `fs.watch`, SHA-256 deduplication, monotonic `revision`). Feeds initial snapshots into `stagePluginHandle` and live updates via `hostToken`-authenticated `pushPluginSettings`, exposing deep-frozen `addonHost.getSettings()` and `addonHost.onSettingsChange(cb)` strictly to active trusted plugins declaring `settingsBridge` (zero renderer-to-main write IPC).
    - `renderer-injector.js`: executes the World `998` kernel (`kernel-bundle.cjs`) once per committed document generation, uses a **CSP-safe two-phase staged-handle protocol** (`stagePluginHandle` -> `consumeStagedHandle` -> `clearStagedHandle`) so `hostToken` never appears in plugin execution code and zero `eval`/`new Function` is needed, aborts in-flight injection loops via `navAttemptSeq` on `did-start-navigation` without bricking the live document on aborted navigation, rotates unconditionally on `did-navigate` (including `reload()`) and `render-process-gone`, and caps recorded renderer error fields.
  - **Preload (`src/runtime/preload/preload-bridge.js` -> `dist/runtime/preload/preload-bridge.cjs`)**: single-file sandboxed preload (`require('electron')` only), zero Page World `0` exposure, single-claim `window.__addonHostBootstrap.claim(nonce)` in Isolated World `998`.
  - **Renderer Kernel (`src/runtime/renderer/` -> `dist/runtime/renderer/kernel-bundle.cjs`)**:
    - `kernel.js`: frozen, host-token-authenticated World `998` kernel exposing capability-scoped plugin handles (`mountSlot`, `injectStyle`, `openModal`, `openPopover`, `observeRegion`, `registerSettingsTab`, `registerAction`, `isElementInsideIgnored`, `addManagedListener`, `runSafe`, `onDispose`, `dispose`).
    - `slot-manager.js`: Option B2 Shadow DOM slots (`v2` defaults `shadow: true` returning inner `<div class="addon-host-slot-root">` `HTMLElement`; `v1` defaults `shadow: false`; `document-transform` always light DOM), `isConnected` SPA detach recovery, and anchor-miss `null` fail-open semantics.
    - `style-manager.js`: escape- and line-continuation-decoded CSS sanitizer, `@`-rule backslash rejection & strict allowlist, top-level `;`-statement splitting, `:has()` & sibling-combinator blocking, owner auto-scoping, and multi-surface `Map<slotId, Set<ShadowRoot>>` style routing.
    - `modal-portal.js`: native `<dialog>.showModal()` + `popover="manual"` LIFO stack (popovers mounted inside active `<dialog>` to avoid modal inertness), restricted `{ shadow: false }` guard, `<dialog>` `close` & popover `toggle` synchronization, IME-safe (`isComposing`/`229`/`defaultPrevented`) `Escape` handling, and `PortalArbiter` state notifications.
    - `ignore-guard.js`: Shadow-DOM-aware `composedPath()` & DOM-node-first (`typeof nodeType === 'number'`) ignore/no-translate guard.
    - `region-observer.js` & `settings-tab-coordinator.js`: host-managed DOM observer and fail-open settings tab registry.
- **`src/profiles/antigravity.js` & Composition Roots (`bin/addon-host.js`, `src/index.js`)**:
  - Wires `ANTIGRAVITY_HOST_PROFILE` and Electron ports (`HostLifecyclePort`, `AddonStorePort`, `TrustPolicyPort`) into `createCliApp(...)`. Any other desktop host can supply its own profile and/or ports without modifying `src/core/` or `src/cli/`.
